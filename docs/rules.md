# 玩法规则

从首页的麻将卡片进入玩法大厅，再选择基础麻将、四川血战到底或广东鸡平胡。创建房间时保存所选玩法的 ID 和版本。通过房间码或邀请链接加入时，按房间已保存的版本行牌。[玩法注册方式](architecture/mahjong.md#新增玩法和游戏)

## 四川麻将 · 血战到底

四人使用 108 张万、条、筒牌。各家先选三张同门牌，同时向下一家交换，再各选一门定缺。四人都提交后才公开定缺。超时由系统从最多的一门选三张，或把手牌最少的一门定为缺门。行牌时手里有缺门牌就必须先打，缺门牌不能碰、杠或用于和牌。本桌不吃牌。

允许碰、直杠、暗杠、补杠、抢补杠，以及同一张牌多家胡。已经胡牌的人退场，三家胡牌或牌墙摸尽时结算。放过点胡后，在自己再次摸牌前只可点胡更高番的牌。

- 平胡零番，碰碰胡一番，七对两番，清一色两番。每根加一番，七对中的四张同牌也算一根。抢杠胡、杠上花、杠上炮各加一番，三番封顶。
- 点胡由出牌者按 `2^番` 支付每一位和牌者。自摸由其余还在打的玩家各付 `2^番 + 1`。
- 直杠由点杠者付两分，暗杠由其余在场者各付两分，补杠由其余在场者各付一分。杠后从墙尾补牌。
- 牌墙耗尽时，只对未胡者查花猪、查大叫和退杠分。手牌与副露三门齐全者向每位非花猪付八分。非花猪且未听牌者向每位听牌者支付其最高基础胡分。未听者退还本局收到的杠分。

本桌固定向下一家换牌，暂未采用呼叫转移和末四张必胡，结算为单局积分。[流程参考：DeskPark 四川麻将](https://github.com/solitern/DeskPark/tree/main/packages/engine/src/games/sichuan) · [Riichi Advanced 四川血战](https://github.com/EpicOrange/riichi_advanced/blob/main/documentation/sichuan.md)

## 广东麻将 · 鸡平胡（无花）

四人使用 136 张牌，包含万、条、筒、风牌和三元牌。下家可以吃，各家可以碰、直杠、暗杠、补杠及抢补杠。四组一对或七对可胡，鸡胡零番起胡。胡优先于碰、杠和吃，同优先级由离出牌者最近的座位获得。一人胡后结束，全员未胡且牌墙耗尽时零分流局。

- 四组顺子加一对计平胡一番。七对两番，碰碰胡和混一色各三番，清一色和字一色各六番。自摸、杠上开花、抢杠胡各一番，可叠加，六番封顶。
- 每位付款者按 `2^番` 支付。自摸三家付，点胡与抢杠只由出牌者或补杠者付。杠后从墙尾补牌，杠本身不单独计分。

这是本项目选定的无花、零番起胡桌规。广东各地另有不同起胡门槛、包牌、花牌和番型约定。[流派与规则选项参考：广东麻将训练器](https://github.com/WYHCIPUC/gd-mahjong-trainer/blob/HEAD/src/domain/rulesets/jipinghu.json)

## 基础麻将

136 张牌，可吃、碰、直杠、暗杠和杠后补牌。吃、碰后先出一张牌。按四组一对或七对胡牌，一人胡后结束。自摸三家各付一分，点胡由出牌者付一分，流局零分。
