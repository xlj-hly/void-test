# 玩法规则

从首页的麻将卡片进入玩法大厅，再选择基础麻将、四川血战到底或广东鸡平胡。创建房间时保存所选玩法的 ID 和版本。通过房间码或邀请链接加入时，按房间已保存的版本行牌。[玩法注册方式](architecture/mahjong.md#新增玩法和游戏)

## 四川麻将 · 血战到底

四人使用 108 张万、条、筒牌。各家先选三张同门牌，同时向下一家交换，再各选一门定缺。四人都提交后才公开定缺。超时由系统从最多的一门选三张，或把手牌最少的一门定为缺门。行牌时手里有缺门牌就必须先打，缺门牌不能碰、杠或用于和牌。本桌不吃牌。

允许碰、直杠、暗杠、补杠、抢补杠，以及同一张牌多家胡。已经胡牌的人退场，三家胡牌或牌墙摸尽时结算。放过点胡后，在自己再次摸牌前只可点胡更高番的牌。

- 平胡零番，碰碰胡一番，七对两番，清一色两番。每根加一番，七对中的四张同牌也算一根。抢杠胡、杠上花、杠上炮各加一番，三番封顶。
- 点胡由出牌者按 `2^番` 支付每一位和牌者。自摸由其余还在打的玩家各付 `2^番 + 1`。
- 直杠由点杠者付两分，暗杠由其余在场者各付两分，补杠由其余在场者各付一分。杠后从墙尾补牌。
- 牌墙耗尽时，只对未胡者查花猪、查大叫和退杠分。手牌与副露三门齐全者向每位非花猪付八分。非花猪且未听牌者向每位听牌者支付其最高基础胡分。未听者退还本局收到的杠分。

本桌固定向下一家换牌，暂未采用呼叫转移和末四张必胡，结算为单局积分。[流程参考：DeskPark 四川麻将](https://github.com/solitern/DeskPark/tree/main/packages/engine/src/games/sichuan) · [Riichi Advanced 四川血战](https://github.com/EpicOrange/riichi_advanced/blob/main/documentation/sichuan.md)

## 广东麻将 · 鸡平胡（无花）

本桌以腾讯公布的无花鸡平胡桌规为依据。四人使用 136 张万、条、筒和字牌。首庄随机，庄家 14 张，闲家 13 张。每副胡牌或流局后，房主可开下一副，积分累计。庄家胡牌（含多响）或流局时连庄，其他情况由庄家的下家坐庄。门风按当前庄家起东依次分配。四家轮庄完毕换圈风，依东、南、西、北打完四圈后本场结束。[腾讯广东麻将规则](https://game.qq.com/new05/help/gdmj.htm)

### 行牌与胡牌

- 下家可吃，各家可碰或直杠，自己摸牌后可暗杠或补杠。吃、碰后先出牌。胡牌优先于碰和杠，碰和杠优先于吃。同张牌允许多家胡，收到全部响应或响应超时后一起结算。
- 胡牌形状为四组一对或十三幺。七对按普通形状判断，单凭七对结构不能胡。放过可胡的牌后，自己再次摸牌或实际吃、碰、杠前，不能胡别人给出的同种牌。放过多种牌分别记录，超时视作放过。
- 摸牌从墙头取，杠后从墙尾补。只允许抢补杠，补杠被抢时保留原碰，取消补牌。直杠所用弃牌仍按普通点胡优先。摸完最后一张后仍可自摸或点胡，最后弃牌仅响应胡牌，无人胡则流局。

### 番型

| 番数 | 普通番型 | 特殊番型 |
| --- | --- | --- |
| 0 | 鸡胡 | |
| 1 | 平胡（全顺子） | |
| 2 | 碰碰胡、混一色 | |
| 4 | | 清一色、混碰 |
| 5 | | 清碰、混幺九、小三元、小四喜 |
| 6 | | 字一色、清幺九、大三元、大四喜、九莲宝灯、十三幺 |

普通番型取最高基础番，加自摸、门风刻、圈风刻各一番，每组三元刻加一番，最终封顶三番。门风和圈风相同时可分别加番。同一手牌有多种合法拆法时取最高番。特殊番型按最高番计算，同番可显示多个牌型。九莲须以同一花色的 `1112345678999` 九面听为胡前结构。

庄家起手成胡为天和。无鸣牌或杠打断时，闲家胡庄家第一张弃牌为人和，闲家第一次正常摸牌自摸为地和，三者按六番。杠上开花、抢补杠、自摸最后一张牌（一称海底捞月）和一炮三响最低三番，原来的特殊番高于三番时保留高番。

### 支付与包牌

- 每份为 `2^番` 分。普通点胡由出牌者给每名胡者付一份，自摸由其余三家各付一份。一炮三响逐家结算，每位胡者最低三番。杠本身无独立杠分，流局零分。
- 抢补杠由补杠者给每名胡者各付三份。直杠后立即补牌自摸由点杠者付三份，继续开其他杠后按新的杠来源判断。
- 吃、碰或直杠做成第四组公开副露（杠按一组计）且单吊时，供牌者包自摸。单吊牌在自己的手牌和副露中已经有四张时，不能形成听口。每名供牌者只包自己最先触发十二张落地的玩家。已公开两组三元刻或三组风刻时，供出剩下一组的人对大三元或大四喜自摸包牌。碰后补杠保留原供牌责任。
- 同时符合多个包牌条件时依次采用即时点杠、特殊牌型、十二张落地，责任人付三份。同番型与包牌结算按每名胡者独立计算。

已有广东房间也使用本页规则。恢复旧牌局时保留牌张和已完成的结算，过胡与包牌等原先未保存的记录从恢复时开始计算。

## 基础麻将

136 张牌，可吃、碰、直杠、暗杠和杠后补牌。吃、碰后先出一张牌。按四组一对或七对胡牌，一人胡后结束。自摸三家各付一分，点胡由出牌者付一分，流局零分。
